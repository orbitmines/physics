#### the derivation

**lean = \frac{c̄}{DEG}**  
<sub>definition · lattice.lean</sub>  

an annihilation gives the direction it went one extra way of being taken, while every other way out of that point still weighs exactly what it did before - and there are DEG of those. So the lean is a step against DEG: what the annihilation bought, over the alternatives it did not take. The numerator is c̄ rather than a bare 1 because what it bought is a step, and a step is c̄

**c̄ = 1**  
<sub>premise · counts/what-the-tiling-fixes</sub>  

a step's worth of lean is what one annihilation buys a path, and a step is c̄ - one cell a tick, the lattice's own speed. Its value in those units is one, which is a statement about the units and not about the quantity. A count of the tiling, taken off the geometry itself with nothing run and nothing fitted

**DEG = 12**  
<sub>premise · counts/what-the-tiling-fixes</sub>  

the ways out of a point on fcc-12 - the exits it has, counted. A count of the tiling, taken off the geometry itself with nothing run and nothing fitted

**lean = \frac{c̄}{DEG} = 1/12**  
<sub>derived · a ratio of counts</sub>  

```
lean = \frac{c̄}{DEG}
= \frac{1}{12}
= 1/12
```

c̄ is 1 and DEG is 12, both counted off the tiling, so the ratio is 1/12 exactly - and it is worth reading as c̄/DEG rather than as the number, because on another lattice it is a different number and the same ratio
