#### the derivation

**lean_1 = n · \frac{c̄}{DEG}**  
<sub>definition · gravity.law</sub>  

an annihilation gives the direction it went one extra way of being taken, so after n of them that direction has 1 + n ways against the 1 each that the DEG alternatives still have. The surplus is n, each worth a step, against DEG - and a path's lean is that. Note what is NOT here: nothing divides by anything that grows with n, so the lean is linear in the count and has no ceiling

### the result

**lean_1 = n · \frac{c̄}{DEG}**

| lattice | D | DEG | box | ticks |
|---|---|---|---|---|
| `fcc-12` | 3 | 12 | 21 | 120 |
| `cubic-6` | 3 | 6 | 21 | 120 |
| `square-4` | 2 | 4 | 41 | 120 |
| `line-2` | 1 | 2 | 61 | 120 |

#### the derivation

**lean_1 = n · \frac{c̄}{DEG}**  
<sub>definition · gravity.law</sub>  

an annihilation gives the direction it went one extra way of being taken, so after n of them that direction has 1 + n ways against the 1 each that the DEG alternatives still have. The surplus is n, each worth a step, against DEG - and a path's lean is that. Note what is NOT here: nothing divides by anything that grows with n, so the lean is linear in the count and has no ceiling
