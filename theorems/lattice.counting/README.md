### the result

**l.ball\paren{\bar{R}}.count = \bar{R}^{D}**

#### the derivation

**shell \propto r^{\paren{D - 1}}**  
<sub>theorem · how many places are r steps out</sub>  

```
exits(p): the ways out of a point, DEG of them
steps: where one exit leads - and that is all the rules say about where anything is
D of those ways are independent, so places within r steps ∝ r^{D}
shell(r) = ball(r) - ball(r-1) ∝ r^{D-1}
```

the rules give a point, DEG ways out of it, and where each one leads - and nothing else about where anything is. So how far is how many steps were taken, and how many places are that far out is a count of walks. D is how many of those ways are independent, so within r steps there are r choices along each of D and the places within r go as r^{D}; the places at exactly r are the difference between two of those, which is r^{D-1}. Every step is whole and every place counted once, so this is the count itself and not an approximation to one

**l.ball\paren{\bar{R}}.count = \bar{R}^{D}**  
<sub>theorem · the ball and the shell it is bounded by</sub>  

```
l.ball(R).count = sum of l.shell up to R = \bar{R}^{D}
```

the places WITHIN R steps, which is the shell summed over every radius up to R - one power higher, by the same count of walks
