#### the derivation

**missing = k_metric - k_retard**  
<sub>definition · gravity.joining</sub>  

so what the retarded route does not account for is the difference, and it is B's term less the clock convention. THE GAP IS NOT A DISAGREEMENT BUT A MISSING TERM: the retarded force is the metric with the space part left out. That is why the two are compared rather than multiplied - multiplying would count A twice and still never mention B

**k_metric = k_A + k_B**  
<sub>definition · gravity.joining</sub>  

so the metric's whole velocity correction is the two together, 2 beta^(2) - which is what differentiating it gives directly, so the split accounts for all of it

**missing = k_A + k_B - k_retard**  
<sub>derived · substituting</sub>  

```
missing = k_metric - k_retard
k_metric = k_A + k_B
missing = k_A + k_B - k_retard
```

k_metric is not a primitive of this theory - it is k_A + k_B, so it stands in for itself here and the result is multiplied out

**k_B = 1**  
<sub>definition · gravity.joining</sub>  

and the piece from the space part B carries another 1.00 beta^(2). This is space being stretched where the count is high, which is not a statement about when anything arrives - so nothing about travel time can produce it

**missing = 1 + k_A - k_retard**  
<sub>derived · substituting</sub>  

```
missing = k_A + k_B - k_retard
k_B = 1
missing = 1 + k_A - k_retard
```

k_B is not a primitive of this theory - it is 1, so it stands in for itself here and the result is multiplied out

**k_retard = k_A + 1/2**  
<sub>definition · gravity.joining</sub>  

the retarded force carries A's beta^(2) - its two branches and its clock are exactly what a late arrival and a slow clock do - plus a half from whose clock the answer is quoted per, which this folder makes a switch of. That is 3/2 on the receiver's clock and 1 on the lattice's

**missing = 1/2**  
<sub>derived · substituting</sub>  

```
missing = 1 + k_A - k_retard
k_retard = 1/2 + k_A
missing = 1/2
```

k_retard is not a primitive of this theory - it is 1/2 + k_A, so it stands in for itself here and the result is multiplied out

**missing = 1/2**  
<sub>derived · which is a number</sub>  

1/2 has nothing left in it that varies, so it is 1/2 exactly
