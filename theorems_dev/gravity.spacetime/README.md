#### the derivation

**A·B = A · B**  
<sub>definition · gravity.spacetime</sub>  

the metric is ds² = -A dt² + B dr², so what there is to ask about the two together is their product. Multiplied out it is (1 - 2u)(1 + 2u) = 1 - 4u², which is one to this order - the two readings are INVERSES. That is what Schwarzschild has in isotropic form, and it is not put in here: it follows from both being readings of one count, so what the count does to the ways through a point it does inversely to the ways round it

**A = 1 - 2u**  
<sub>definition · gravity.spacetime</sub>  

the lean makes a clock run slow where the count is high - that is the first reading, the one gravity.law takes, and in the potential it is 1 - 2u. The factor of two is the normalisation u carries, not a step

<sub>derived · substituting</sub>  

```

A = 1 - 2·u

```

A is not a primitive of this theory - it is 1 - 2·u, so it stands in for itself here and the result is multiplied out

<sub>derived · to first order</sub>

#### the derivation

**A·B = A · B**  
<sub>definition · gravity.spacetime</sub>  

the metric is ds² = -A dt² + B dr², so what there is to ask about the two together is their product. Multiplied out it is (1 - 2u)(1 + 2u) = 1 - 4u², which is one to this order - the two readings are INVERSES. That is what Schwarzschild has in isotropic form, and it is not put in here: it follows from both being readings of one count, so what the count does to the ways through a point it does inversely to the ways round it

**A = 1 - 2u**  
<sub>definition · gravity.spacetime</sub>  

the lean makes a clock run slow where the count is high - that is the first reading, the one gravity.law takes, and in the potential it is 1 - 2u. The factor of two is the normalisation u carries, not a step

**A·B = B - 2·B·u**  
<sub>derived · substituting</sub>  

```
A·B = A·B
A = 1 - 2·u
A·B = B - 2·B·u
```

A is not a primitive of this theory - it is 1 - 2·u, so it stands in for itself here and the result is multiplied out

**B = 1 + 2u**  
<sub>cited · gravity.metric</sub>  

established earlier by gravity.metric, on this same theory and lattice - the working is there rather than repeated here

**A·B = 1 - 4·u^(2)**  
<sub>derived · substituting</sub>  

```
A·B = B - 2·B·u
B = 1 + 2·u
A·B = 1 - 4·u^(2)
```

B is not a primitive of this theory - it is 1 + 2·u, so it stands in for itself here and the result is multiplied out

**u << 1**  
<sub>definition · gravity.spacetime</sub>  

the potential is small wherever this is asked - far outside anything dense - so its square is smaller still and the first order is the whole of it

**A·B = 1**  
<sub>derived · to first order</sub>  

```
A·B = 1 - 4·u^(2)
u << 1
A·B = 1
```

u is much smaller than one, so powers of it beyond the first are smaller still and are dropped. What is kept is everything to first order in it - stated rather than assumed, and the line above is what it was before

**A·B = 1**  
<sub>derived · which is a number</sub>  

1 has nothing left in it that varies, so it is 1 exactly
