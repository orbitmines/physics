- D = 3 - how many dimensions fcc-12 has
- DEG = 12 - the ways out of a point on fcc-12 - the exits it has, counted

#### the derivation

**\lambda_1 = \lambda/(1 - g_1)**  
<sub>definition · scatter.harmonics</sub>  

SO EACH MULTIPOLE HAS ITS OWN RANGE. Removal is absorption plus scattering-out and the return is scattering-in weighted by g_l, so the l-th mode decays at sigma_a + sigma_s(1 - g_l) and reaches lambda_l = lambda/(1 - g_l). A shape of order l is therefore visible out to about lambda_l and no further, and the ratio between two of them at a radius is what a picture of an orbital IS

**\lambda_1 = \frac{g_1}{killing}**  
<sub>derived · as a ratio</sub>  

\lambda_1 is g_1 over killing, which written out is \frac{g_1}{killing} - kept in the counts rather than worked out, so that whatever uses it can cancel against them

**g_1 = (1 + 2\cos\Theta)/3**  
<sub>cited · turn.kernel</sub>  

established earlier by turn.kernel, on this same theory and lattice - the working is there rather than repeated here

**\lambda_1 = \frac{\Theta}{killing}**  
<sub>derived · substituting</sub>  

```
\lambda_1 = \frac{g_1}{killing}
g_1 = \Theta
\lambda_1 = \frac{\Theta}{killing}

g_1 is not a primitive of this theory - it is \Theta, so it stands in for itself here and the result is multiplied out
