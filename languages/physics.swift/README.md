## Using it

Swift has no dynamic members, so a Ray object is reached by name: `get(x, "name")`, `call(x, "method", [args])`, `set(x, "name", value)`, `make(Physics.Class, [kw("field", value), ...])`. Every value is a `V` (numbers are `Double`s, lists are shared), and everything that can fail throws a `RayError`.

```swift
import OrbitMinesPhysics

// a theory, and its continuous model on the CPU: a box of cells, the vacuum settled, one body in it
let medium = try call(Physics.G, "medium", [31.0, 96.0, 3.0, 8.0, 1.0])
try set(medium, "local_rays", true)
try call(medium, "add", [try make(Physics.Hole, [kw("x", 15.0), kw("y", 15.0), kw("mx", 0.3), kw("ways", 1.0)])])
try get(medium, "seed")
for _ in 0..<5 { try get(medium, "tick") }
```

## A simulation of sources: the plan

A run is set by a `Plan`: how many sources, how big a box, and four kinds of setting - `Resolution` (how finely the medium reads), `Budget` (how much of the device it may take), `Batching` (how a run larger than the device is carried) and `Output` (what comes back). The plan says what the device must hold before anything runs.

```swift
let plan = try make(Physics.Plan, [kw("sources", 1e9), kw("side", 241.0)])
try set(try get(plan, "budget"), "compact", true)   // twelve bytes a source
print(try str(try call(plan, "report", [V.num(16 * 1073741824.0), V.num(2147483648.0)])))
```
