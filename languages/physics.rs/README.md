## Using it

Rust has no dynamic members, so a Ray object is reached by name: `get(&x, "name")`, `call(&x, "method", args![...])`, `set(&x, "name", &value)`, `make("Class", args![kw("field", &value), ...])`, and a class or a theory by its name: `K("G")`. Every value is a `Value` (numbers are `f64`, lists `Value::List`); an operand may also be a plain `f64`, `bool` or `&str`. The classes are registered once per thread, on first use.

```rust
use orbitmines_physics::*;

// a theory, and its continuous model on the CPU: a box of cells, the vacuum settled, one body in it
let medium = call(&K("G"), "medium", args![31.0, 96.0, 3.0, 8.0, 1.0]);
set(&medium, "local_rays", &true);
call(&medium, "add", args![make("Hole", args![kw("x", &15.0), kw("y", &15.0), kw("mx", &0.3), kw("ways", &1.0)])]);
get(&medium, "seed");
for _ in 0..5 { get(&medium, "tick"); }
```

A Ray program can recurse deeply: run a large one on a thread with a stack of its own (`std::thread::Builder::new().stack_size(1 << 30)`).

## A simulation of sources: the plan

A run is set by a `Plan`: how many sources, how big a box, and four kinds of setting - `Resolution` (how finely the medium reads), `Budget` (how much of the device it may take), `Batching` (how a run larger than the device is carried) and `Output` (what comes back). The plan says what the device must hold before anything runs.

```rust
let plan = make("Plan", args![kw("sources", &1e9), kw("side", &241.0)]);
set(&get(&plan, "budget"), "compact", &true);   // twelve bytes a source
println!("{}", call(&plan, "report", args![16.0 * 1073741824.0, 2147483648.0]));
```
